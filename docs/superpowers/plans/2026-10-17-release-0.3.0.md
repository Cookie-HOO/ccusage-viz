# ccusage-viz 0.3.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prepare, validate, and publish ccusage-viz 0.3.0 from the committed post-v0.2.2 history.

**Architecture:** Keep release preparation limited to package/runtime version metadata, bilingual public release documentation, and fixes required by the existing CI and publication gates. Merge the validated release branch into `main` before creating the GitHub Release tag so the existing PyPI workflow accepts it.

**Tech Stack:** Python 3.11–3.13, uv, pytest, Ruff, ty, GitHub Actions, PyPI Trusted Publishing

**Spec:** `docs/superpowers/specs/2026-10-17-release-0.3.0-design.md`

## Global Constraints

- Release baseline is `v0.2.2` at `ca10dcc7`.
- Target version is exactly `0.3.0`; target tag is exactly `v0.3.0`.
- Add no new product feature during release preparation.
- Publish only from a commit merged into `main`.
- Existing CI and PyPI workflow checks must pass.
